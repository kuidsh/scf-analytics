Prototype · Stellar Community Fund RFP · Web and API Analytics

SCF Analytics

Shows each Stellar project how its API is doing (traffic, errors, speed) and gives SCF one ecosystem-wide view. Web visitors are measured by self-hosted Umami and shown beside it. Traffic goes in as standard OpenTelemetry traces; nothing personal is stored.

ⓘExample data. The four projects are made up. demo/build_demo.py pushed 30 days of generated API traffic through the real ingest, storage, metrics and alert code; the older months of the year view are generated hourly aggregates. The web-analytics numbers are example values shaped like Umami's API responses and run through the real summary code; they are not read from a live Umami. Nothing is deployed.
